📱 Téléphone Android

⬇️ Télécharger l'application
  1. Ouvre le fichier téléchargé.
  2. Si Android demande l'autorisation, accepte « Installer quand même » ou « Autoriser depuis cette source ».
  3. Ouvre Super Modogo depuis ton écran d'accueil.

🍏 iPhone

  1. Ouvre cette page dans Safari (pas Chrome).
  2. Touche le bouton Partager (le carré avec une flèche).
  3. Choisis « Sur l'écran d'accueil », puis Ajouter.
  4. Ouvre Super Modogo depuis ton écran d'accueil.

Ouvrir sur votre téléphone

Pour installer, ouvrez cette page sur un téléphone Android ou un iPhone.
